Today's two golden rules 1. Route order matters. Angular takes the first matching route, not the best one. The wildcard ** goes last, and static paths go above dynamic ones.

📄 src/app/app-routing.module.ts Replace the whole file 
import { NgModule } from '@angular/core';
import { RouterModule, Routes } from '@angular/router';

import { HomeComponent } from './pages/home/home.component';
import { CustomersComponent } from './pages/customers/customers.component';
import { AboutComponent } from './pages/about/about.component';
import { NotFoundComponent } from './pages/not-found/not-found.component';

const routes: Routes = [
  // 1. Default — what shows at the bare localhost:4200
  { path: '', redirectTo: '/home', pathMatch: 'full' },

  // 2. The real screens
  { path: 'home',      component: HomeComponent },
  { path: 'customers', component: CustomersComponent },
  { path: 'about',     component: AboutComponent },

  // 3. The wildcard 404 — ALWAYS LAST
  { path: '**', component: NotFoundComponent }
];

@NgModule({
  imports: [RouterModule.forRoot(routes)],   // forRoot: only in the root routing module
  exports: [RouterModule]                    // ← WITHOUT THIS, routerLink won't work
})
export class AppRoutingModule { }
LineWhy it's there
path: '' with pathMatch: 'full'pathMatch: 'full' means "only when the whole URL is empty". Leave it out and the empty path matches the start of every URL — an infinite redirect loop.
path: 'home' (no leading slash)Angular adds the slash. Writing '/home' gives you a route that never matches.
path: '**'The wildcard. Matches anything, so it must be last — Angular takes the first match, not the best.
RouterModule.forRoot(routes)Sets up the router for the whole app. Used once, here.
exports: [RouterModule]The most-forgotten line in Angular routing. Re-exports the router's directives so your components can use routerLink and <router-outlet>.

Try it yourself — five experiments, each proving one rule from the theory
  1. Prove URLs are real. Type localhost:4200/about straight into the address bar and press Enter. The About screen opens directly. That is why routing matters — the URL is now a genuine address you can bookmark or send to someone.
  2. Prove routerLink is not href. Change the About link to <a href="/about">. Click it and watch the browser's reload spinner — the entire app restarts. Change it back to routerLink and the difference is obvious.
  3. Prove the outlet is required. Comment out <router-outlet></router-outlet>. Now the URL still changes when you click, and nothing appears at all — with no error anywhere. Angular has a component and nowhere to put it. Restore it.
  4. Prove route order matters. Move the { path: '**' } route to the top of the array. Now every single page shows the 404, because every URL matches the wildcard first. Move it back to the bottom. This is the single most common routing bug there is.
  5. Prove exact: true is needed. Remove [routerLinkActiveOptions]="{ exact: true }" from the Home link. Nothing obvious happens yet — now change that link's path from /home to /. It is highlighted on every page, because prefix matching means / matches everything. Put both back.

📄 src/app/pages/customers/customers.component.ts Replace the whole file 
import { Component, OnInit } from '@angular/core';
import { FormBuilder, FormGroup, Validators } from '@angular/forms';
import { Customer } from '../../models/customer';

@Component({
  selector: 'app-customers',
  templateUrl: './customers.component.html',
  styleUrls: ['./customers.component.css']
})
export class CustomersComponent implements OnInit {

  // ── the data: TWO arrays, and this matters ──────────────
  allCustomers: Customer[] = [];    // the master list — never filtered
  customers: Customer[] = [];       // what the table displays

  // ── screen state ────────────────────────────────────────
  searchTerm = '';
  message = '';

  // ── edit mode: null = adding, a number = editing that id ─
  editingId: number | null = null;

  // ── the form (reactive, from Session 3) ─────────────────
  custForm: FormGroup;

  constructor(private fb: FormBuilder) {
    this.custForm = this.fb.group({
      name:    ['', [Validators.required, Validators.minLength(3)]],
      city:    ['', [Validators.required]],
      email:   ['', [Validators.required, Validators.email]],
      balance: [0,  [Validators.required, Validators.min(0)]]
    });
  }

  // getters, so the template stays readable
  get name()    { return this.custForm.get('name'); }
  get city()    { return this.custForm.get('city'); }
  get email()   { return this.custForm.get('email'); }
  get balance() { return this.custForm.get('balance'); }

  ngOnInit(): void {
    this.allCustomers = [
      { id: 1001, name: 'Anoop Kumar',  city: 'Ahmedabad', email: 'anoop@example.com',  balance: 15000 },
      { id: 1002, name: 'Ajay Sharma',  city: 'Pune',      email: 'ajay@example.com',   balance: 0 },
      { id: 1003, name: 'Rekha Nair',   city: 'Kochi',     email: 'rekha@example.com',  balance: 42500 },
      { id: 1004, name: 'Suresh Patel', city: 'Surat',     email: 'suresh@example.com', balance: 8200 }
    ];
    this.customers = this.allCustomers;
  }

  // ── R: SEARCH ───────────────────────────────────────────
  onSearch(): void {
    const t = this.searchTerm.trim().toLowerCase();

    if (t === '') {
      this.customers = this.allCustomers;
      return;
    }

    // ALWAYS filter the master list, never the displayed one
    this.customers = this.allCustomers.filter(c =>
      c.name.toLowerCase().includes(t) ||
      c.city.toLowerCase().includes(t) ||
      c.email.toLowerCase().includes(t)
    );
  }

  clearSearch(): void {
    this.searchTerm = '';
    this.onSearch();
  }

  // ── C: INSERT (U comes in Task 4) ───────────────────────
  onSubmit(): void {
    if (this.custForm.invalid) {
      this.custForm.markAllAsTouched();   // reveal every error at once
      return;
    }

    const newCustomer: Customer = {
      id: this.getNextId(),
      name:    this.custForm.value.name,
      city:    this.custForm.value.city,
      email:   this.custForm.value.email,
      balance: this.custForm.value.balance
    };

    this.allCustomers.push(newCustomer);
    this.message = '✅ Added ' + newCustomer.name + ' (id ' + newCustomer.id + ').';

    this.resetForm();
    this.onSearch();      // re-apply the filter, or the new row won't appear
  }

  // ── D: DELETE ───────────────────────────────────────────
  onDelete(customer: Customer): void {
    const ok = confirm('Delete ' + customer.name + '? This cannot be undone.');
    if (!ok) { return; }

    const i = this.allCustomers.findIndex(c => c.id === customer.id);
    if (i !== -1) {
      this.allCustomers.splice(i, 1);
    }

    if (this.editingId === customer.id) {
      this.resetForm();   // don't stay in edit mode on something that's gone
    }

    this.message = '🗑️ Deleted ' + customer.name + '.';
    this.onSearch();
  }

  // ── helpers ─────────────────────────────────────────────
  private getNextId(): number {
    if (this.allCustomers.length === 0) { return 1001; }
    // highest existing id + 1 — NOT length + 1, which duplicates after a delete
    return Math.max(...this.allCustomers.map(c => c.id)) + 1;
  }

  resetForm(): void {
    this.custForm.reset({ name: '', city: '', email: '', balance: 0 });
    this.editingId = null;
  }

  getTotalBalance(): number {
    let total = 0;
    for (const c of this.customers) { total = total + c.balance; }
    return total;
  }

  trackById(index: number, c: Customer): number {
    return c.id;
  }
}
DecisionWhy it's written that way
allCustomers + customersTwo arrays. Filter the master into the displayed one. If you filter the displayed list, deleting a search character can never bring rows back — you destroyed them.
editingId: number | nullOne field carries the whole insert-versus-update distinction. Task 4 uses it; Session 1's Stretch C is where you met | null.
markAllAsTouched()Without it, clicking Save on an untouched empty form does nothing and shows nothing — the user has no idea why.
Math.max(...ids) + 1Highest id plus one. length + 1 produces duplicate ids the moment anything is deleted.
this.onSearch() after add/deleteEasy to forget. You changed allCustomers, but the table shows customers. Without this the new row seems to vanish.
confirm(...) before deleteNever destroy data on a single click. The browser dialog is ugly but honest — real projects use a styled modal with identical logic.

import { Injectable } from '@angular/core';
import { Customer } from '../models/customer';

@Injectable({ providedIn: 'root' })
export class CustomerService {

  private customers: Customer[] = [
    { id: 1001, name: 'Anoop Kumar',  city: 'Ahmedabad', email: 'anoop@example.com',  balance: 15000 },
    { id: 1002, name: 'Ajay Sharma',  city: 'Pune',      email: 'ajay@example.com',   balance: 0 },
    { id: 1003, name: 'Rekha Nair',   city: 'Kochi',     email: 'rekha@example.com',  balance: 42500 },
    { id: 1004, name: 'Suresh Patel', city: 'Surat',     email: 'suresh@example.com', balance: 8200 }
  ];

  // ── R ───────────────────────────────────────────────────
  getAll(): Customer[] {
    return this.customers;
  }

  getById(id: number): Customer | undefined {
    return this.customers.find(c => c.id === id);
  }

  search(term: string): Customer[] {
    const t = term.trim().toLowerCase();
    if (t === '') { return this.customers; }
    return this.customers.filter(c =>
      c.name.toLowerCase().includes(t) ||
      c.city.toLowerCase().includes(t) ||
      c.email.toLowerCase().includes(t)
    );
  }

  // ── C ───────────────────────────────────────────────────
  add(customer: Customer): Customer {
    customer.id = this.getNextId();
    this.customers.push(customer);
    return customer;
  }

  // ── U ───────────────────────────────────────────────────
  update(customer: Customer): boolean {
    const i = this.customers.findIndex(c => c.id === customer.id);
    if (i === -1) { return false; }
    this.customers[i] = customer;
    return true;
  }

  // ── D ───────────────────────────────────────────────────
  delete(id: number): boolean {
    const i = this.customers.findIndex(c => c.id === id);
    if (i === -1) { return false; }
    this.customers.splice(i, 1);
    return true;
  }

  // ── helpers ─────────────────────────────────────────────
  getTotalBalance(): number {
    let total = 0;
    for (const c of this.customers) { total = total + c.balance; }
    return total;
  }

  private getNextId(): number {
    if (this.customers.length === 0) { return 1001; }
    return Math.max(...this.customers.map(c => c.id)) + 1;
  }
}

import { Injectable } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { Observable } from 'rxjs';
import { map } from 'rxjs/operators';
import { Customer } from '../models/customer';

@Injectable({ providedIn: 'root' })
export class CustomerService {

  // ONE line to change when you switch to your own backend.
  private baseUrl = 'https://jsonplaceholder.typicode.com/users';

  constructor(private http: HttpClient) { }

  // ── R: all ──────────────────────────────────────────────
  getAll(): Observable<Customer[]> {
    return this.http.get<any[]>(this.baseUrl).pipe(
      map(users => users.map(u => this.toCustomer(u)))
    );
  }

  // ── R: one ──────────────────────────────────────────────
  getById(id: number): Observable<Customer> {
    return this.http.get<any>(this.baseUrl + '/' + id).pipe(
      map(u => this.toCustomer(u))
    );
  }

  // ── C ───────────────────────────────────────────────────
  add(customer: Customer): Observable<Customer> {
    return this.http.post<Customer>(this.baseUrl, customer);
  }

  // ── U ───────────────────────────────────────────────────
  update(customer: Customer): Observable<Customer> {
    return this.http.put<Customer>(this.baseUrl + '/' + customer.id, customer);
  }

  // ── D ───────────────────────────────────────────────────
  delete(id: number): Observable<void> {
    return this.http.delete<void>(this.baseUrl + '/' + id);
  }

  /** The API's shape is not our shape. All the conversion lives here. */
  private toCustomer(u: any): Customer {
    return {
      id: u.id,
      name: u.name,
      city: u.address?.city ?? 'Unknown',
      email: u.email,
      balance: u.id * 1000
    };
  }
}

  /** Searching happens locally, on the data we already fetched. */
  onSearch(): void {
    const t = this.searchTerm.trim().toLowerCase();
    if (t === '') {
      this.customers = this.allCustomers;
      return;
    }
    this.customers = this.allCustomers.filter(c =>
      c.name.toLowerCase().includes(t) ||
      c.city.toLowerCase().includes(t) ||
      c.email.toLowerCase().includes(t)
    );
  }

  // ── C and U, over HTTP ──────────────────────────────────
  onSubmit(): void {
    if (this.custForm.invalid) {
      this.custForm.markAllAsTouched();
      return;
    }

    const customer: Customer = {
      id: this.editingId ?? 0,        // 0 for a new one; the SERVER assigns the id
      name:    this.custForm.value.name,
      city:    this.custForm.value.city,
      email:   this.custForm.value.email,
      balance: this.custForm.value.balance
    };

    // Build the right call, then subscribe ONCE.
    // Safe because Observables are lazy — nothing is sent until subscribe.
    const call = this.editingId === null
      ? this.customerService.add(customer)
      : this.customerService.update(customer);

    call.subscribe({
      next: (saved) => {
        this.message = this.editingId === null
          ? '✅ Created on the server with id ' + saved.id + '.'
          : '✅ Updated on the server.';
        this.resetForm();
        this.loadCustomers();         // reload so the screen matches the server
      },
      error: (err) => {
        this.message = '❌ Save failed — nothing was changed on the server.';
        console.error(err);
      }
    });
  }

  // ── D, over HTTP ────────────────────────────────────────
  onDelete(customer: Customer): void {
    if (!confirm('Delete ' + customer.name + '? This cannot be undone.')) { return; }

    this.customerService.delete(customer.id).subscribe({
      next: () => {
        // Only NOW, once the server has confirmed it
        this.message = '🗑️ Deleted ' + customer.name + ' on the server.';
        if (this.editingId === customer.id) { this.resetForm(); }
        this.loadCustomers();
      },
      error: (err) => {
        this.message = '❌ Delete failed — the customer is still there.';
        console.error(err);
      }
    });
  }

  getTotalBalance(): number {
    let total = 0;
    for (const c of this.customers) { total = total + c.balance; }
    return total;
  }

Hit a CORS error? That is expected, and it is not an Angular problem blocked by CORS policy: No 'Access-Control-Allow-Origin' header means the browser refused to let port 4200 talk to port 8080. The request never reached your server. Nothing you change in Angular will help.

Fix 1 (quick): @CrossOrigin(origins = "http://localhost:4200") on the controller — and restart Spring Boot.
Fix 2 (better): a WebMvcConfigurer with addCorsMappings, applied application-wide.
Fix 3 (no CORS at all): run ng build and copy dist/hello-world/browser/* into Spring Boot's src/main/resources/static/. Both are then served from port 8080 — same origin, so CORS never applies. This is how many teams actually deploy.
