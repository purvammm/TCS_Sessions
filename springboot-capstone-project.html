The book catalogue: CRUD in clean layers

A warm-up you already know from Session 3, written the way production code is. Try to finish today using no solutions at all.

Entity designJava records as DTOsConstructor injection@Transactional & dirty checking201 + Location header
Three habits that start today
  • Records for DTOs. public record BookResponse(Long id, String title) {} gives you a constructor, accessors (title(), not getTitle()), equals and toString in one line, and it's immutable. Entities stay normal classes because JPA needs a no-arg constructor and mutable fields.
  • Constructor injection. Mark dependencies private final and take them in the constructor. With one constructor Spring injects it automatically, no @Autowired needed. You can't forget a dependency, and tests can call new BookService(fakeRepo).
  • Entities never leave the service layer. Controllers receive and return DTOs only. The service maps between them.

Design rules: table name books. A protected no-arg constructor for JPA, plus a public constructor Book(isbn, title, publishedYear, totalCopies) that starts availableCopies equal to totalCopies. Getters for everything. Setters for isbn, title and publishedYear only. Copies change through a method, changeTotalCopies(int newTotal).

Why no setter for availableCopies? If any code can call setAvailableCopies(-5), nothing protects the numbers. Changing them only through methods on Book gives you one place to enforce the rules. You'll rely on this on Day 4.

package com.tcs.training.library.entity;

import jakarta.persistence.Column;
import jakarta.persistence.Entity;
import jakarta.persistence.GeneratedValue;
import jakarta.persistence.GenerationType;
import jakarta.persistence.Id;
import jakarta.persistence.Table;

@Entity
@Table(name = "books")
public class Book {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, unique = true, length = 13)
    private String isbn;

    @Column(nullable = false, length = 200)
    private String title;

    @Column(name = "published_year")
    private Integer publishedYear;

    @Column(name = "total_copies", nullable = false)
    private int totalCopies;

    @Column(name = "available_copies", nullable = false)
    private int availableCopies;

    protected Book() {
        // required by JPA
    }

    public Book(String isbn, String title, Integer publishedYear, int totalCopies) {
        this.isbn = isbn;
        this.title = title;
        this.publishedYear = publishedYear;
        this.totalCopies = totalCopies;
        this.availableCopies = totalCopies;   // a new book starts with every copy on the shelf
    }

    /** Day 1 version: nobody can borrow yet, so every copy is on the shelf. Day 4 makes this smarter. */
    public void changeTotalCopies(int newTotal) {
        this.totalCopies = newTotal;
        this.availableCopies = newTotal;
    }

    public Long getId() { return id; }
    public String getIsbn() { return isbn; }
    public void setIsbn(String isbn) { this.isbn = isbn; }
    public String getTitle() { return title; }
    public void setTitle(String title) { this.title = title; }
    public Integer getPublishedYear() { return publishedYear; }
    public void setPublishedYear(Integer publishedYear) { this.publishedYear = publishedYear; }
    public int getTotalCopies() { return totalCopies; }
    public int getAvailableCopies() { return availableCopies; }
}

1.4
BookService with transactionspackage service

Five public methods: create(BookRequest), findAll(), findById(Long), update(Long, BookRequest), delete(Long). All return DTOs (or nothing). A private helper getBook(Long id) loads the entity or throws ResourceNotFoundException.

Transactions in two lines Put @Transactional(readOnly = true) on the class so every method is a read-only transaction by default. Then put a plain @Transactional on the methods that write. Inside a transaction, an entity you loaded is managed: if you change its fields, Hibernate writes the change on commit without a save() call. This is called dirty checking.
💡 Hint 1
Use org.springframework.transaction.annotation.Transactional (it has readOnly), not the jakarta.transaction one. For findAll: repository.findAll().stream().map(BookResponse::from).toList().
🧭 Hint 2
@Transactional
public BookResponse update(Long id, BookRequest request) {
    Book book = getBook(id);                       // 404 if missing
    book.setTitle(request.title());                // ... and the other fields
    book.changeTotalCopies(request.totalCopies());
    return BookResponse.from(book);                // no save(): dirty checking writes it on commit
}

package com.tcs.training.library.service;

import com.tcs.training.library.dto.BookRequest;
import com.tcs.training.library.dto.BookResponse;
import com.tcs.training.library.entity.Book;
import com.tcs.training.library.exception.ResourceNotFoundException;
import com.tcs.training.library.repository.BookRepository;
import java.util.List;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
@Transactional(readOnly = true)
public class BookService {

    private final BookRepository bookRepository;

    public BookService(BookRepository bookRepository) {   // constructor injection: no @Autowired needed
        this.bookRepository = bookRepository;
    }

    @Transactional
    public BookResponse create(BookRequest request) {
        Book book = new Book(request.isbn(), request.title(), request.publishedYear(), request.totalCopies());
        return BookResponse.from(bookRepository.save(book));
    }

    public List<BookResponse> findAll() {
        return bookRepository.findAll().stream()
                .map(BookResponse::from)
                .toList();
    }

    public BookResponse findById(Long id) {
        return BookResponse.from(getBook(id));
    }

    @Transactional
    public BookResponse update(Long id, BookRequest request) {
        Book book = getBook(id);
        book.setIsbn(request.isbn());
        book.setTitle(request.title());
        book.setPublishedYear(request.publishedYear());
        book.changeTotalCopies(request.totalCopies());
        return BookResponse.from(book);   // no save() needed: the entity is managed, changes flush on commit
    }

    @Transactional
    public void delete(Long id) {
        bookRepository.delete(getBook(id));
    }

    private Book getBook(Long id) {
        return bookRepository.findById(id)
                .orElseThrow(() -> new ResourceNotFoundException("Book", id));
    }
}

package com.tcs.training.library.controller;

import com.tcs.training.library.dto.BookRequest;
import com.tcs.training.library.dto.BookResponse;
import com.tcs.training.library.service.BookService;
import java.net.URI;
import java.util.List;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.DeleteMapping;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.PutMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequestMapping("/api/books")
public class BookController {

    private final BookService bookService;

    public BookController(BookService bookService) {
        this.bookService = bookService;
    }

    @PostMapping
    public ResponseEntity<BookResponse> create(@RequestBody BookRequest request) {
        BookResponse created = bookService.create(request);
        return ResponseEntity.created(URI.create("/api/books/" + created.id())).body(created);
    }

    @GetMapping
    public List<BookResponse> findAll() {
        return bookService.findAll();
    }

    @GetMapping("/{id}")
    public BookResponse findById(@PathVariable Long id) {
        return bookService.findById(id);
    }

    @PutMapping("/{id}")
    public BookResponse update(@PathVariable Long id, @RequestBody BookRequest request) {
        return bookService.update(id, request);
    }

    @DeleteMapping("/{id}")
    public ResponseEntity<Void> delete(@PathVariable Long id) {
        bookService.delete(id);
        return ResponseEntity.noContent().build();
    }
}

Check yourself

Why return a DTO instead of the Book entity?
The entity is your database schema. Returning it ties your public API to the table: rename a column and clients break. It can also leak fields (from Day 6, a password hash), cause infinite JSON loops with relationships, and trigger lazy-loading errors. A DTO is a separate contract you control.
What does readOnly = true actually do?
It tells Hibernate the transaction won't write. Hibernate skips dirty checking and flushing, which saves work, and some databases and drivers can route or optimise read-only transactions. It also documents intent.
Why 201 + Location instead of 200?
HTTP defines 201 Created for "a new resource exists now", and Location tells the client its URL. Clients and tools can follow it without guessing how URLs are built.

import org.springframework.web.bind.annotation.RestControllerAdvice;

import org.springframework.web.servlet.mvc.method.annotation.ResponseEntityExceptionHandler;

@RestControllerAdvice
public class GlobalExceptionHandler extends ResponseEntityExceptionHandler {

    @ExceptionHandler(ResourceNotFoundException.class)
    public ProblemDetail handleNotFound(ResourceNotFoundException ex) {
        ProblemDetail problem = ProblemDetail.forStatusAndDetail(HttpStatus.NOT_FOUND, ex.getMessage());
        problem.setTitle("Resource not found");
        return problem;
    }

    @ExceptionHandler(BusinessRuleException.class)
    public ProblemDetail handleBusinessRule(BusinessRuleException ex) {
        ProblemDetail problem = ProblemDetail.forStatusAndDetail(HttpStatus.CONFLICT, ex.getMessage());
        problem.setTitle("Business rule violated");
        return problem;
    }

    @ExceptionHandler(DataIntegrityViolationException.class)
    public ProblemDetail handleDataIntegrity(DataIntegrityViolationException ex) {
        ProblemDetail problem = ProblemDetail.forStatusAndDetail(HttpStatus.CONFLICT,
                "The request conflicts with existing data (for example a duplicate value)");
        problem.setTitle("Data conflict");
        return problem;
    }


    @ExceptionHandler(BadRequestException.class)
    public ProblemDetail handleBadRequest(BadRequestException ex) {
        ProblemDetail problem = ProblemDetail.forStatusAndDetail(HttpStatus.BAD_REQUEST, ex.getMessage());
        problem.setTitle("Bad request");
        return problem;
    }

    @Override
    protected ResponseEntity<Object> handleMethodArgumentNotValid(MethodArgumentNotValidException ex,
            HttpHeaders headers, HttpStatusCode status, WebRequest request) {
        Map<String, String> errors = new LinkedHashMap<>();
        ex.getBindingResult().getFieldErrors()
                .forEach(error -> errors.putIfAbsent(error.getField(), error.getDefaultMessage()));

        ProblemDetail problem = ex.getBody();
        problem.setTitle("Validation failed");
        problem.setDetail("One or more fields are invalid");
        problem.setProperty("errors", errors);
        return handleExceptionInternal(ex, problem, headers, status, request);
    }

  • availableOnly (optional, default false): if true, only books with at least one copy on the shelf.
  • Defaults: page size 10, sorted by title A→Z. A client can never get more than 50 rows per page.
  • Sorting is allowed only by title, publishedYear, availableCopies. Anything else → 400 (BadRequestException).
  • Response shape, using your own PageResponse<T> record:
{"content":[ ...books... ],"page":0,"size":10,"totalElements":2,"totalPages":1}
Why your own PageResponse? Spring Data's Page serialises to a large JSON object whose shape isn't guaranteed to stay the same, and Spring logs a warning if you return it directly. A five-field record is a stable contract that you control.
💡 Hint 1
Add a Pageable pageable parameter to the controller method; Spring fills it from page, size and sort. Set defaults with @PageableDefault(size = 10, sort = "title"). The 50-row cap is one property: spring.data.web.pageable.max-page-size=50. Repository methods can take a Pageable and return a Page<Book>, and page.map(BookResponse::from) converts the contents.

@Service
@Transactional(readOnly = true)
public class BookService {

    private static final List<String> SORTABLE_FIELDS = List.of("title", "publishedYear", "availableCopies");

    private final BookRepository bookRepository;

    public BookService(BookRepository bookRepository) {
        this.bookRepository = bookRepository;
    }

    @Transactional
    public BookResponse create(BookRequest request) {
        if (bookRepository.existsByIsbn(request.isbn())) {
            throw new BusinessRuleException("A book with ISBN " + request.isbn() + " already exists");
        }
        Book book = new Book(request.isbn(), request.title().trim(), request.publishedYear(), request.totalCopies());
        return BookResponse.from(bookRepository.save(book));
    }

    public PageResponse<BookResponse> search(String title, boolean availableOnly, Pageable pageable) {
        pageable.getSort().forEach(order -> {
            if (!SORTABLE_FIELDS.contains(order.getProperty())) {
                throw new BadRequestException(
                        "Cannot sort by '" + order.getProperty() + "'. Allowed: " + SORTABLE_FIELDS);
            }
        });
        String titleFilter = (title == null) ? "" : title.trim();
        return PageResponse.from(
                bookRepository.search(titleFilter, availableOnly, pageable).map(BookResponse::from));
    }

    public BookResponse findById(Long id) {
        return BookResponse.from(getBook(id));
    }

    @Transactional
    public BookResponse update(Long id, BookRequest request) {
        Book book = getBook(id);
        if (bookRepository.existsByIsbnAndIdNot(request.isbn(), id)) {
            throw new BusinessRuleException("A book with ISBN " + request.isbn() + " already exists");
        }
        book.setIsbn(request.isbn());
        book.setTitle(request.title().trim());
        book.setPublishedYear(request.publishedYear());
        book.changeTotalCopies(request.totalCopies());
        return BookResponse.from(book);
    }

    @Transactional
    public void delete(Long id) {
        bookRepository.delete(getBook(id));
    }

    private Book getBook(Long id) {
        return bookRepository.findById(id)
                .orElseThrow(() -> new ResourceNotFoundException("Book", id));
    }
}

Check yourself

400 or 409: how do you choose?
400 means the request itself is malformed or invalid, and you can tell without touching the database (blank title, ISBN of 3 digits). 409 means the request is well-formed but conflicts with the current state (that ISBN is taken, no copies left). Sending the same 409 request later might succeed; the same 400 request never will.
Why cap the page size and whitelist sort fields?
Without a cap, ?size=1000000 makes your server load the whole table into memory, which is an easy denial-of-service. Without a whitelist, an unknown field throws an exception deep inside Spring Data, giving a 500, and a sortable field you didn't intend to expose can leak information through the order of the results.
Where should validation live: DTO, service, or database?
All three, for different things. The DTO checks shape and format (cheap, gives clear messages). The service checks rules that need data (duplicate ISBN, loan limits). The database enforces the last line of defence (NOT NULL, UNIQUE), which also catches race conditions.

@Service
@Transactional(readOnly = true)
public class BookService {

    private static final List<String> SORTABLE_FIELDS = List.of("title", "publishedYear", "availableCopies");

    private final BookRepository bookRepository;
    private final AuthorService authorService;

    public BookService(BookRepository bookRepository, AuthorService authorService) {
        this.bookRepository = bookRepository;
        this.authorService = authorService;
    }

    @Transactional
    public BookResponse create(BookRequest request) {
        if (bookRepository.existsByIsbn(request.isbn())) {
            throw new BusinessRuleException("A book with ISBN " + request.isbn() + " already exists");
        }
        Author author = authorService.getAuthor(request.authorId());
        Book book = new Book(request.isbn(), request.title().trim(), request.publishedYear(),
                request.totalCopies(), author);
        return BookResponse.from(bookRepository.save(book));
    }

    public BookResponse findById(Long id) {
        return BookResponse.from(getBook(id));
    }

    public PageResponse<BookResponse> search(String title, Long authorId, boolean availableOnly, Pageable pageable) {
        pageable.getSort().forEach(order -> {
            if (!SORTABLE_FIELDS.contains(order.getProperty())) {
                throw new BadRequestException(
                        "Cannot sort by '" + order.getProperty() + "'. Allowed: " + SORTABLE_FIELDS);
            }
        });
        String titleFilter = (title == null) ? "" : title.trim();
        return PageResponse.from(
                bookRepository.search(titleFilter, authorId, availableOnly, pageable).map(BookResponse::from));
    }

    @Transactional
    public BookResponse update(Long id, BookRequest request) {
        Book book = getBook(id);
        if (bookRepository.existsByIsbnAndIdNot(request.isbn(), id)) {
            throw new BusinessRuleException("A book with ISBN " + request.isbn() + " already exists");
        }
        book.setIsbn(request.isbn());
        book.setTitle(request.title().trim());
        book.setPublishedYear(request.publishedYear());
        book.changeTotalCopies(request.totalCopies());
        if (!book.getAuthor().getId().equals(request.authorId())) {
            book.setAuthor(authorService.getAuthor(request.authorId()));
        }
        return BookResponse.from(book);   // no save() needed: the entity is managed, changes flush on commit
    }

    @Transactional
    public void delete(Long id) {
        bookRepository.delete(getBook(id));
    }

    Book getBook(Long id) {
        return bookRepository.findById(id)
                .orElseThrow(() -> new ResourceNotFoundException("Book", id));
    }
}

What open-in-view does, and why you turn it off By default Spring keeps the database session open for the whole HTTP request, including after your service returns. Lazy fields then quietly load from the controller or during JSON writing, which hides N+1 problems and holds a connection longer than needed. With it off, lazy data must be loaded inside your @Transactional service. That's why this project maps entities to DTOs in the service. If you map in a controller with it off, you'll see LazyInitializationException.

Common fixes: a join fetch in JPQL, an @EntityGraph on the repository method, or Hibernate batch fetching. @EntityGraph(attributePaths = "author") is the cleanest here because it works with paged queries without a separate count query.

@ManyToOne and @OneToOne default to EAGER; @OneToMany and @ManyToMany default to LAZY. EAGER on a to-one relationship loads the related row every time, often with extra queries you never asked for. Set LAZY everywhere and fetch what each use case needs.

The library's rules

  1. R1 A loan lasts 14 days (configurable).
  2. R2 A member may have at most 3 active loans (configurable).
  3. R3 You can't borrow a book with no copies on the shelf.
  4. R4 A member can't hold two copies of the same book at once.

import com.tcs.training.library.exception.BusinessRuleException;
import com.tcs.training.library.exception.ResourceNotFoundException;
import com.tcs.training.library.repository.LoanRepository;
import java.math.BigDecimal;
import java.time.Clock;
import java.time.LocalDate;
import java.time.temporal.ChronoUnit;
import java.util.List;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
@Transactional(readOnly = true)
public class LoanService {

    private final LoanRepository loanRepository;
    private final BookService bookService;
    private final MemberService memberService;
    private final LoanProperties rules;
    private final Clock clock;

    public LoanService(LoanRepository loanRepository, BookService bookService, MemberService memberService,
                       LoanProperties rules, Clock clock) {
        this.loanRepository = loanRepository;
        this.bookService = bookService;
        this.memberService = memberService;
        this.rules = rules;
        this.clock = clock;
    }

    @Transactional
    public LoanResponse borrow(Long bookId, Long memberId) {
        Member member = memberService.getMember(memberId);
        return borrow(bookService.getBook(bookId), member);
    }


    private LoanResponse borrow(Book book, Member member) {
        LocalDate today = LocalDate.now(clock);

        if (loanRepository.existsByMemberIdAndReturnedOnIsNullAndDueOnBefore(member.getId(), today)) {
            throw new BusinessRuleException("Member has an overdue loan. Return it before borrowing again");
        }
        if (loanRepository.countByMemberIdAndReturnedOnIsNull(member.getId()) >= rules.maxActiveLoans()) {
            throw new BusinessRuleException("Member already has " + rules.maxActiveLoans() + " active loans");
        }
        if (loanRepository.existsByMemberIdAndBookIdAndReturnedOnIsNull(member.getId(), book.getId())) {
            throw new BusinessRuleException("Member already has a copy of '" + book.getTitle() + "'");
        }

        book.borrowCopy();   // throws if no copies are left
        Loan loan = new Loan(book, member, today, today.plusDays(rules.loanDays()));
        return LoanResponse.from(loanRepository.save(loan), today);
    }

    @Transactional
    public LoanResponse returnLoan(Long loanId) {
        Loan loan = loanRepository.findById(loanId)
                .orElseThrow(() -> new ResourceNotFoundException("Loan", loanId));
        if (!loan.isActive()) {
            throw new BusinessRuleException("Loan " + loanId + " was already returned on " + loan.getReturnedOn());
        }

        LocalDate today = LocalDate.now(clock);
        long daysLate = Math.max(0, ChronoUnit.DAYS.between(loan.getDueOn(), today));
        BigDecimal fee = rules.feePerDay().multiply(BigDecimal.valueOf(daysLate));

        loan.markReturned(today, fee);
        loan.getBook().returnCopy();
        return LoanResponse.from(loan, today);
    }

    public List<LoanResponse> findByMember(Long memberId) {
        memberService.getMember(memberId);   // 404 if the member does not exist
        return toResponses(loanRepository.findByMemberIdOrderByBorrowedOnDesc(memberId));
    }


    public List<LoanResponse> findOverdue() {
        LocalDate today = LocalDate.now(clock);
        return toResponses(loanRepository.findByReturnedOnIsNullAndDueOnBeforeOrderByDueOn(today));
    }

    private List<LoanResponse> toResponses(List<Loan> loans) {
        LocalDate today = LocalDate.now(clock);
        return loans.stream().map(loan -> LoanResponse.from(loan, today)).toList();
    }
}

        String titleFilter = (title == null) ? "" : title.trim();
        return PageResponse.from(
                bookRepository.search(titleFilter, authorId, availableOnly, pageable).map(BookResponse::from));
    }

    @Transactional
    public BookResponse update(Long id, BookRequest request) {
        Book book = getBook(id);
        if (bookRepository.existsByIsbnAndIdNot(request.isbn(), id)) {
            throw new BusinessRuleException("A book with ISBN " + request.isbn() + " already exists");
        }
        book.setIsbn(request.isbn());
        book.setTitle(request.title().trim());
        book.setPublishedYear(request.publishedYear());
        book.changeTotalCopies(request.totalCopies());
        if (!book.getAuthor().getId().equals(request.authorId())) {
            book.setAuthor(authorService.getAuthor(request.authorId()));
        }
        return BookResponse.from(book);   // no save() needed: the entity is managed, changes flush on commit
    }

    @Transactional
    public void delete(Long id) {
        Book book = getBook(id);
        if (loanRepository.existsByBookIdAndReturnedOnIsNull(id)) {
            throw new BusinessRuleException("Cannot delete '" + book.getTitle() + "' while copies are on loan");
        }
        bookRepository.delete(book);
    }

    Book getBook(Long id) {
        return bookRepository.findWithAuthorById(id)
                .orElseThrow(() -> new ResourceNotFoundException("Book", id));
    }
}

Check yourself

Why BigDecimal and not double for the fee?
double is binary floating point, so 0.1 + 0.2 gives 0.30000000000000004. Over many transactions money drifts. BigDecimal stores exact decimal values, and the column is NUMERIC(10,2) to match.
Why are the rule checks in LoanService, but R3 and R8 in Book?
R3 and R8 only need the book's own fields, so the book can protect itself. R2, R4 and R5 need other data (the member's other loans), which an entity can't query. That makes them service rules.
What is a "lost update" and how does @Version prevent it?
Two transactions read availableCopies = 1, both subtract one, both write 0, and two loans now exist for one copy. With @Version, each update says "only if version is still 5". The first sets it to 6; the second updates 0 rows, and Hibernate throws instead of silently overwriting.

Members get passwords and rolesNever store a password, only its hash.
  • enum Role { MEMBER, LIBRARIAN }.
  • Member gains passwordHash (column password_hash, max 100) and role (stored as text: @Enumerated(EnumType.STRING)). The constructor takes both.
  • MemberRequest gains password: required, 8–72 characters.
  • MemberResponse gains role. It must never include the hash.
  • MemberService.register hashes the password with an injected PasswordEncoder and always assigns Role.MEMBER. Also add Member getMemberByEmail(String email) for 6.6.
Two details that matter
  • Why max 72? BCrypt only uses the first 72 bytes of a password. Longer passwords give a false sense of security.
  • Why EnumType.STRING? The default, ORDINAL, stores 0 and 1. If someone later adds a role at the start of the enum, every existing user's role silently changes.

Why turning CSRF off is correct here CSRF attacks trick a browser into sending a request with a cookie it stored automatically. This API uses no session cookie: the client sends credentials on every request (stateless). There's no cookie to abuse, so CSRF protection only gets in the way. A browser app with session login should keep it on.

import org.springframework.context.annotation.Configuration;

import org.springframework.security.config.Customizer;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configurers.AbstractHttpConfigurer;
import org.springframework.security.config.http.SessionCreationPolicy;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.security.web.SecurityFilterChain;

@Configuration
public class SecurityConfig {

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
            .csrf(AbstractHttpConfigurer::disable)   // stateless REST API: no browser session, no CSRF cookie
            .sessionManagement(session -> session.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .headers(headers -> headers.frameOptions(frame -> frame.sameOrigin()))   // H2 console uses frames
            .authorizeHttpRequests(auth -> auth
                // public
                .requestMatchers("/h2-console/**").permitAll()   // dev only: the console has its own login
                .requestMatchers(HttpMethod.POST, "/api/members").permitAll()
                .requestMatchers("/actuator/health", "/actuator/info").permitAll()
                .requestMatchers("/swagger-ui.html", "/swagger-ui/**", "/v3/api-docs/**").permitAll()
                // any logged-in user can browse the catalogue
                .requestMatchers(HttpMethod.GET, "/api/books/**", "/api/authors/**").hasAnyRole("MEMBER", "LIBRARIAN")
                // members manage their own loans
                .requestMatchers("/api/me/**").hasRole("MEMBER")
                // everything else under /api is staff only
                .requestMatchers("/api/**").hasRole("LIBRARIAN")
                .anyRequest().authenticated())
            .httpBasic(Customizer.withDefaults());
        return http.build();
    }

    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();
    }
}

import com.tcs.training.library.config.LoanProperties;
import com.tcs.training.library.dto.LoanResponse;
import com.tcs.training.library.entity.Book;
import com.tcs.training.library.entity.Loan;
import com.tcs.training.library.entity.Member;
import com.tcs.training.library.exception.BusinessRuleException;
import com.tcs.training.library.exception.ResourceNotFoundException;
import com.tcs.training.library.repository.LoanRepository;
import java.math.BigDecimal;
import java.time.Clock;
import java.time.LocalDate;
import java.time.temporal.ChronoUnit;
import java.util.List;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
@Transactional(readOnly = true)
public class LoanService {

    private final LoanRepository loanRepository;
    private final BookService bookService;
    private final MemberService memberService;
    private final LoanProperties rules;
    private final Clock clock;

    public LoanService(LoanRepository loanRepository, BookService bookService, MemberService memberService,
                       LoanProperties rules, Clock clock) {
        this.loanRepository = loanRepository;
        this.bookService = bookService;
        this.memberService = memberService;
        this.rules = rules;
        this.clock = clock;
    }

    @Transactional
    public LoanResponse borrow(Long bookId, Long memberId) {
        Member member = memberService.getMember(memberId);
        return borrow(bookService.getBook(bookId), member);
    }

    @Transactional
    public LoanResponse borrowForMember(String email, Long bookId) {
        Member member = memberService.getMemberByEmail(email);
        return borrow(bookService.getBook(bookId), member);
    }

    private LoanResponse borrow(Book book, Member member) {
        LocalDate today = LocalDate.now(clock);

        if (loanRepository.existsByMemberIdAndReturnedOnIsNullAndDueOnBefore(member.getId(), today)) {
            throw new BusinessRuleException("Member has an overdue loan. Return it before borrowing again");
        }
        if (loanRepository.countByMemberIdAndReturnedOnIsNull(member.getId()) >= rules.maxActiveLoans()) {
            throw new BusinessRuleException("Member already has " + rules.maxActiveLoans() + " active loans");
        }
        if (loanRepository.existsByMemberIdAndBookIdAndReturnedOnIsNull(member.getId(), book.getId())) {
            throw new BusinessRuleException("Member already has a copy of '" + book.getTitle() + "'");
        }

        book.borrowCopy();   // throws if no copies are left
        Loan loan = new Loan(book, member, today, today.plusDays(rules.loanDays()));
        return LoanResponse.from(loanRepository.save(loan), today);
    }

    @Transactional
    public LoanResponse returnLoan(Long loanId) {
        Loan loan = loanRepository.findById(loanId)
                .orElseThrow(() -> new ResourceNotFoundException("Loan", loanId));
        if (!loan.isActive()) {
            throw new BusinessRuleException("Loan " + loanId + " was already returned on " + loan.getReturnedOn());
        }

        LocalDate today = LocalDate.now(clock);
        long daysLate = Math.max(0, ChronoUnit.DAYS.between(loan.getDueOn(), today));
        BigDecimal fee = rules.feePerDay().multiply(BigDecimal.valueOf(daysLate));

        loan.markReturned(today, fee);
        loan.getBook().returnCopy();
        return LoanResponse.from(loan, today);
    }

    public List<LoanResponse> findByMember(Long memberId) {
        memberService.getMember(memberId);   // 404 if the member does not exist
        return toResponses(loanRepository.findByMemberIdOrderByBorrowedOnDesc(memberId));
    }

    public List<LoanResponse> findByMemberEmail(String email) {
        Member member = memberService.getMemberByEmail(email);
        return toResponses(loanRepository.findByMemberIdOrderByBorrowedOnDesc(member.getId()));
    }

    public List<LoanResponse> findOverdue() {
        LocalDate today = LocalDate.now(clock);
        return toResponses(loanRepository.findByReturnedOnIsNullAndDueOnBeforeOrderByDueOn(today));
    }

    private List<LoanResponse> toResponses(List<Loan> loans) {
        LocalDate today = LocalDate.now(clock);
        return loans.stream().map(loan -> LoanResponse.from(loan, today)).toList();
    }
}

Check yourself

Authentication vs authorisation, and 401 vs 403?
Authentication answers "who are you?"; failing it gives 401 (the name is historical; it really means "unauthenticated"). Authorisation answers "are you allowed to do this?"; failing it gives 403. Asha with a wrong password gets 401. Asha trying to add a book gets 403.
Why BCrypt instead of SHA-256?
SHA-256 is designed to be fast, so an attacker with a stolen database can try billions of guesses per second. BCrypt is deliberately slow (with an adjustable cost) and adds a random salt to every hash, so identical passwords produce different hashes and precomputed tables don't help.
Is HTTP Basic safe?
Only over HTTPS. Basic sends the email and password, base64-encoded (not encrypted), on every request. That's acceptable for an internal API behind TLS, and it's why real public APIs usually swap the password for a short-lived token (the JWT stretch goal).

Own your schema with FlywaySQL migrations instead of Hibernate guessing

Until now Hibernate created the tables from your entities (create-drop). That's fine for learning and dangerous in production: there's no history, no review, and a renamed field can drop a column. With Flyway you write each schema change as a numbered SQL file. It runs each file once, in order, and records it in a flyway_schema_history table.

  1. Add the Flyway starter (and its test starter).
  2. Write src/main/resources/db/migration/V1__create_tables.sql with all four tables, matching your entities exactly: names, types, lengths, nullability, unique keys, foreign keys, and an index on each loan foreign key.
  3. Write V2__sample_catalogue.sql with 3 authors and 3 books, so the app has data to demo.
  4. Switch Hibernate to spring.jpa.hibernate.ddl-auto=validate: it now only checks that the tables match the entities, and refuses to start if they don't. Remove show-sql too.

Check yourself

Why validate instead of update in production?
update lets Hibernate alter tables based on your entities, with no review, no rollback plan and no history. It never drops or renames columns safely. validate changes nothing; it fails fast if the reviewed migrations and the code disagree.
Why not expose all Actuator endpoints?
Endpoints like env, configprops, heapdump and loggers can reveal configuration and secrets, or change behaviour at runtime. Expose the minimum publicly. If you need more, put them on a separate management port or behind the LIBRARIAN role.

/h2-console gives 404Boot 4 needs the spring-boot-h2console dependency (Initializr adds it when you choose H2) and spring.h2.console.enabled=true. Log in with JDBC URL jdbc:h2:mem:library.
H2 console is blank or "refused to connect" after Day 6Allow /h2-console/** and set headers.frameOptions(f -> f.sameOrigin()), as in the reference SecurityConfig.
Validation annotations are ignored (bad data returns 201)@Valid missing before @RequestBody, or the spring-boot-starter-validation dependency is missing.

Every POST returns 403 in @WebMvcTest, even with @WithMockUserYour SecurityConfig isn't loaded in the slice, so default CSRF protection applies. Add @Import(SecurityConfig.class).
No qualifying bean of type 'H2ConsoleProperties' in controller testsYou used PathRequest.toH2Console(). Use requestMatchers("/h2-console/**") instead.
