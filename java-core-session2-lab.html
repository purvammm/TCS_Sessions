// 1. Narrowing access - not allowed
@Override

TASK 4▶ Dynamic Dispatch & the Field-Hiding SurpriseTheory slides 14–16
Goal Prove that methods are polymorphic but fields are not. This is the most commonly misunderstood behaviour in Java, and a favourite interview question.
Predict before running — write your answers down Given Parent p = new Child(); where both declare a field label and a method getLabel(): what does p.label print, and what does p.getLabel() print?
📄DispatchDemo.javacreate this file
class Parent {
    String label = "PARENT-FIELD";

    String getLabel()      { return "PARENT-METHOD"; }
    static String tag()    { return "PARENT-STATIC"; }

    void describe() {
        // Called on a Child object: which versions run?
        System.out.println("    inside describe(): field=" + label
                           + ", method=" + getLabel());
    }
}

class Child extends Parent {
    String label = "CHILD-FIELD";          // HIDES the parent field - bad practice!

    @Override
    String getLabel()      { return "CHILD-METHOD"; }
    static String tag()    { return "CHILD-STATIC"; }   // HIDES, does not override
}

public class DispatchDemo {
    public static void main(String[] args) {
        Parent p = new Child();       // reference type Parent, object type Child

        System.out.println("Via a Parent reference to a Child object:");
        System.out.println("  p.label       = " + p.label);        // ?
        System.out.println("  p.getLabel()  = " + p.getLabel());   // ?
        System.out.println("  p.getClass()  = " + p.getClass().getSimpleName());

        System.out.println("\nVia a Child reference:");
        Child c = new Child();
        System.out.println("  c.label       = " + c.label);
        System.out.println("  c.getLabel()  = " + c.getLabel());
        System.out.println("  ((Parent) c).label = " + ((Parent) c).label);

        System.out.println("\nInherited method calling both:");
        p.describe();

        System.out.println("\nStatic methods are NOT polymorphic:");
        System.out.println("  Parent.tag()  = " + Parent.tag());
        System.out.println("  Child.tag()   = " + Child.tag());
    }
}
Expected output — the surprise is on line 2
Via a Parent reference to a Child object: p.label = PARENT-FIELD ← FIELD: reference type wins! p.getLabel() = CHILD-METHOD ← METHOD: object type wins p.getClass() = Child Via a Child reference: c.label = CHILD-FIELD c.getLabel() = CHILD-METHOD ((Parent) c).label = PARENT-FIELD ← same object, different answer! Inherited method calling both: inside describe(): field=PARENT-FIELD, method=CHILD-METHOD Static methods are NOT polymorphic: Parent.tag() = PARENT-STATIC Child.tag() = CHILD-STATIC
Why this happens Field access is resolved at compile time from the reference type — the compiler simply looks at the declared type and picks that field. Instance method calls are resolved at runtime from the object type, via invokevirtual. So the very same object gives two different answers for label depending on how you look at it.

The practical lesson: never shadow a field. Keep fields private and expose them through methods, and this whole class of confusion disappears.

📄Account.javacreate this file
public abstract class Account {

    private final String accountNumber;      // private + final = safe
    private final String holder;
    protected double balance;                // protected: subclasses adjust it

    protected Account(String accountNumber, String holder, double openingBalance) {
        if (openingBalance < 0) {
            throw new InvalidAmountException(openingBalance);
        }
        this.accountNumber = accountNumber;
        this.holder = holder;
        this.balance = openingBalance;
    }

    // ===== ABSTRACT: every concrete subclass MUST supply these =====
    public abstract double interestRate();
    public abstract String accountType();

    // ===== TEMPLATE METHOD: the algorithm is fixed, the rate varies =====
    public final double applyInterest() {
        double interest = balance * interestRate();
        balance += interest;
        return interest;
    }

    // ===== SHARED CONCRETE BEHAVIOUR: written once =====
    public void deposit(double amount) {
        if (amount <= 0) throw new InvalidAmountException(amount);
        balance += amount;
    }

    // Overridable: the MINIMUM balance rule differs per account type
    protected double minimumBalance() {
        return 1000.0;
    }

    public void withdraw(double amount) throws InsufficientFundsException {
        if (amount <= 0) throw new InvalidAmountException(amount);
        double allowed = balance - minimumBalance();
        if (amount > allowed) {
            throw new InsufficientFundsException(
                String.format("%s: cannot withdraw %.2f (min balance %.2f must remain)",
                              accountType(), amount, minimumBalance()),
                amount - allowed);
        }
        balance -= amount;
    }

    public double getBalance()       { return balance; }
    public String getAccountNumber() { return accountNumber; }
    public String getHolder()        { return holder; }

    @Override
    public String toString() {
        return String.format("%-8s %-14s %-14s %12.2f  @%.2f%%",
            accountNumber, holder, accountType(), balance, interestRate() * 100);
    }
}

📄PortfolioDemo.javacreate this file
public class PortfolioDemo {

    public static void main(String[] args) {

        // ONE array, declared as the PARENT type, holding FOUR different objects
        Account[] portfolio = {
            new SavingsAccount     ("AC1001", "Priya Sharma",  50000),
            new CurrentAccount     ("AC1002", "Rahul Verma",   80000, 25000),
            new FixedDepositAccount("AC1003", "Anita Desai",  200000, 12),
            new SalaryAccount      ("AC1004", "Vikram Rao",     1200)
        };

        System.out.println("=== Before interest ===");
        for (Account a : portfolio) System.out.println(a);

        // ===== THE PAYOFF: one loop, four behaviours, no 'if' about type =====
        System.out.println("\n=== Applying interest ===");
        double totalInterest = 0;
        for (Account a : portfolio) {
            double interest = a.applyInterest();      // POLYMORPHIC CALL
            totalInterest += interest;
            System.out.printf("%-14s credited %10.2f%n", a.accountType(), interest);
        }
        System.out.printf("Total interest paid out: %.2f%n", totalInterest);

        System.out.println("\n=== After interest ===");
        for (Account a : portfolio) System.out.println(a);

        // ===== Overridden minimumBalance() changes withdrawal rules per type =====
        System.out.println("\n=== Withdrawal rules differ per type ===");
        tryWithdraw(portfolio[0], 45000);   // Savings: must keep 1000
        tryWithdraw(portfolio[1], 95000);   // Current: overdraft allows going negative
        tryWithdraw(portfolio[2], 1000);    // FD: always refused
        tryWithdraw(portfolio[3], 1242);    // Salary: may go to zero

        System.out.println("\n=== Final state ===");
        for (Account a : portfolio) System.out.println(a);
    }

    static void tryWithdraw(Account account, double amount) {
        try {
            account.withdraw(amount);
            System.out.printf("OK      %-14s -%.2f  -> balance %.2f%n",
                              account.accountType(), amount, account.getBalance());
        } catch (InsufficientFundsException e) {
            System.out.println("DENIED  " + e.getMessage());
        }
    }
}

public interface Taxable {

    double TDS_RATE = 0.10;                  // implicitly public static final

    double taxableIncome();                  // implicitly public abstract

    // DEFAULT method: shared logic living in an interface (Java 8+)
    default double taxDue() {
        double income = taxableIncome();
        return isExempt(income) ? 0.0 : income * TDS_RATE;
    }

    // STATIC helper on the interface itself
    static boolean isExempt(double income) {
        return income < 10000;
    }
}

public class CapabilityDemo {

    public static void main(String[] args) {
        Account[] portfolio = {
            new SavingsAccount     ("AC1001", "Priya Sharma",  50000),
            new CurrentAccount     ("AC1002", "Rahul Verma",   80000, 25000),
            new FixedDepositAccount("AC1003", "Anita Desai",  200000, 12),
            new SalaryAccount      ("AC1004", "Vikram Rao",     1200)
        };

        double totalTax = 0;

        for (Account a : portfolio) {
            System.out.println(a.accountType() + " (" + a.getAccountNumber() + ")");

            // Pattern matching for instanceof (Java 16+): test and bind in one step
            if (a instanceof Printable p) {
                p.printStatement();
            } else {
                System.out.println("  |  (no statement available)");
            }

            if (a instanceof Taxable t) {
                double tax = t.taxDue();
                totalTax += tax;
                System.out.printf("  |  taxable income %.2f, TDS due %.2f%n",
                                  t.taxableIncome(), tax);
            } else {
                System.out.println("  |  not taxable");
            }
        }

        System.out.printf("%nTotal TDS across portfolio: %.2f%n", totalTax);
        System.out.println("Exemption threshold check: " + Taxable.isExempt(5000));
        System.out.println("TDS_RATE constant from the interface: " + Taxable.TDS_RATE);
    }
}

import java.util.Objects;

public class Customer {

    private final int    id;
    private final String name;

    public Customer(int id, String name) {
        this.id = id;
        this.name = name;
    }

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        Customer other = (Customer) o;
        return id == other.id && Objects.equals(name, other.name);
    }

    // STEP 1: comment this whole method out and run. STEP 2: put it back and run again.
    @Override
    public int hashCode() {
        return Objects.hash(id, name);        // SAME fields as equals()
    }

    @Override
    public String toString() {
        return "Customer{id=" + id + ", name='" + name + "'}";
    }
}

public class EqualsDemo {

interface Shape {
    double area();
    double perimeter();

    default String describe() {                 // shared, written once
        return String.format("%-10s area %8.2f  perimeter %8.2f",
                             getClass().getSimpleName(), area(), perimeter());
    }
}

class Circle implements Shape {
    private final double radius;
    Circle(double radius) { this.radius = radius; }
    @Override public double area()      { return Math.PI * radius * radius; }
    @Override public double perimeter() { return 2 * Math.PI * radius; }
}

class Rectangle implements Shape {
    private final double width, height;
    Rectangle(double width, double height) { this.width = width; this.height = height; }
    @Override public double area()      { return width * height; }
    @Override public double perimeter() { return 2 * (width + height); }
}

class Triangle implements Shape {
    private final double a, b, c;
    Triangle(double a, double b, double c) { this.a = a; this.b = b; this.c = c; }
    @Override public double perimeter() { return a + b + c; }
    @Override public double area() {                       // Heron's formula
        double s = perimeter() / 2;
        return Math.sqrt(s * (s - a) * (s - b) * (s - c));
    }
}

// Added LAST, with zero changes to main() below
class Square implements Shape {
    private final double side;
    Square(double side) { this.side = side; }
    @Override public double area()      { return side * side; }
    @Override public double perimeter() { return 4 * side; }
}

public class GoodShapes {
    public static void main(String[] args) {
        Shape[] shapes = {                       // typed as Shape, not Object
            new Circle(3),
            new Rectangle(4, 5),
            new Triangle(3, 4, 5),
            new Square(2.5)
        };

        double total = 0;
        for (Shape s : shapes) {                 // no instanceof, no casts
            System.out.println(s.describe());
            total += s.area();
        }
        System.out.printf("%nTotal area: %.2f%n", total);

        // Bonus: sort by area - a taste of Session 3
        java.util.Arrays.sort(shapes, java.util.Comparator.comparingDouble(Shape::area));
        System.out.println("\nSorted by area (smallest first):");
        for (Shape s : shapes) System.out.println(s.describe());
    }
}

constructor X cannot be applied to given typesParent has no no-arg constructor. Add an explicit super(...) as the first line of your child constructor.
call to super must be first statement in constructorMove super(...) to the very top — nothing may come before it.

attempting to assign weaker access privilegesAn override cannot reduce visibility. public stays public.
